# 📚 SQL Server Full Practice – From Zero to Advanced

This repository represents a complete practical journey in SQL Server, covering fundamental to advanced database concepts.
It is designed as a step-by-step training project to build strong SQL skills through structured scripts and real-world examples.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 📌 Project Overview

This project covers:

• DDL (Data Definition Language)
• DML (Data Manipulation Language)
• DQL (Data Query Language)
• Constraints
• Indexes
• Joins
• Views
• Aggregate Functions
• Group By & Having
• Exists
• Union
• Case Statement
• Backup & Restore

The goal is to move from understanding database structure to writing optimized professional queries.

## 🗂 File Descriptions

### 1️⃣ Constraints.sql

Covers all SQL Server constraints:

* Primary Key
* Foreign Key
* NOT NULL
* DEFAULT
* CHECK
* UNIQUE
* Clustered & Non-Clustered Indexes

Includes:

* Creating constraints
* Dropping constraints
* Modifying constraints
* Index creation & deletion

### 2️⃣ DDL.sql (Data Definition Language)

Contains database structure operations:

* Create Database
* Drop Database
* Create Table
* Drop Table
* Alter Table

  * Add Column
  * Rename Column
  * Rename Table
  * Modify Column
  * Delete Column
* Backup & Restore Database

### 3️⃣ DML.sql (Data Manipulation Language)

Handles working with data:

* INSERT

1. Open SQL Server Management Studio
2. Execute each file separately
3. Follow comments inside each script
4. Restore sample databases when required (HR_Database / Shop_Database)
